# CHAPTER 7 Indexing for high performance

Indexes (a.k.a keys in MySQL) are data structures taht storage engies use to finds row quickly.

Indexes are critical for good performance and becoem more important as your data grows larger.

# Indexing Basics

Think about the index of a book.

```sql
SELECT first_name FROM sakila.actor WHERE actor_id = 5;
```

Theres' an index on the `actior_id` column, so MySQL uses the index to find rows whose actor_id is 5.
It performs a lookup on the values in the index and returns any rows contains teh specified value.

An index contains values from one or more columns in a table.

If you index more than one column order is very important because MySQL can only search efficiently on teh leftmost prefix of the index.

An index on 2 columns != 2 indexes in 2 columns
