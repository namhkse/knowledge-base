# Chossing Optimal Data types

MySQL supports a large variety of data types.

The simple guidelines can help you make better choices
- Smaller is usually better: they use less space on the disk, in memory, and in the CPU cache
- Simple is good
- Avoid NULL if possble: 
  It's harder for MySQL to optimize queries that refer to nullable columns because 
  they make indexes, index statistics and value comparisions more complicated.
