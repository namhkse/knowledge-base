# Expectations of an Architecture

There are 8 core expectations palced on a software architect:

1. Make architecture decisions

    An architect is expected to define the architecture decisions and desing principles used to guide technology
    decisions with the team, the department or across teh enterprise.

    Guide is the key operative word in this first expectation. 
    An architect should guide rather than specify technology choices.

    An architect makes a decision to use React.js for FE. the architect is making a technical decision rather
    than an architectural decision or design principle that help the development team make choices. 

    Instead, an architect should instrcut development teams to use a *reactive-based framework for frontend web develpment*. The development team in makign the choice between Angular, React.js, Vue or other reactive-based
    web frameworks.

2. Continually analyze the architecture

    An architect is expected to continually analyze the architecture and current technology environment and
    then recommmend solutions for improvement.

- Keep current with latest trends

    An architect is exprected to keep current with the latest technology and industry trends.

- Ensure compliance with decisions
- diverse exposure and experience
- have business domain knowledge
- possess interpersonal skills
