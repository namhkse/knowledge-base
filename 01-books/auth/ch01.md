# Session and state management in ASP.NET Core

HTTP is a stateless protocol.

# Cookies

Cookies store data across requests.
Because cookies are sent with every request, their size should be kept to a minimum.

Idealy, only an identifier should be stored in a cookie with the data stored by the app.

Browsers restrict cookie size to 4096 bytes.

The cookie can store the user's name, account name, or user ID. 
The cookie can be used to access the user's personalized settings, such as their website background color.

# Session state

Session state is an ASP.NET Core scenario for storage of user data while the user browsers a web app.
Session state uses a store maintained by the app to persist data across requests from a client.

Critical data should be stored in the user database and cached in session only as a performance optimization.

ASP.NET Core maintains session state by providing a cookie to the client that contains a session ID.
- Is sent to the app with each request.
- Is used by the app to fetch session data.

## Configure session state

Middleware for managing session state is inluded. To enable the session middleware:
- Configure the `IDistirubtedCache`.
- Add service `AddSession`.
- Use session middleware `UseSession`.

`HttpContext.Session` can't be accessed before `UseSession` has been called.

## Load session state asynchronously

The default session provider in ASP.NET Core loads session records from the underlying `IDistributedCache` backing store asynchronously.

# TempData

ASP.NET Core exposes the Razor Pages TempData or Controller TempData. This property stores data until it's read in another request.

# Query strings

A limited amount of data can be passed from one request to another request by adding it to the new request's query string.

# Hidden fields

Data can be saved in hidden form fields and posted back to the next requests.
This is common in multi-page forms.

# HttpContext.Items

A collection is used to store data while processing a single request.
The collection is discared after a request si processed.

# Cache

Caching is an efficient way to store and retrieve data.
The app can control the lifetime of cached items.
