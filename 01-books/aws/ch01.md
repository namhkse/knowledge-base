AWS service categories
- Compute
- Networking
- Storage
- Database
- Application management
- Security and identity

1. EC2 - a server instance, virtual
2. Lamda - Serverless application architecture
3. Auto Scaling - Copies of runnign EC2 instance
4. Elastic Load Balancing
5. Elastic Container Service - container technologies
6. Elastic Beenstalk

Netwroking services:

Storage services:
