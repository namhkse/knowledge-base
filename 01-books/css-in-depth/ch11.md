# 11.1 Gradients

## 11.1.1 Uisng multiple color stops

You can define a gradient with multiple colors.
Which are each called a color stop.
The gradient can accept any number of color stops, each separated by a comma. 
You can also set the position of these colors stop in the gradient function.

```css
background-image: linear-gradient(90deg,red 0%, white 20%, blue);
```

The gradient fades from red on 0% to white in 20%.

### Stripes

If you place 2 colors stps at the same position, the gradient's color will
swith from one to the other, rather than a smooth transition.

```css
background-image: linear-gradient(90deg,red 20%, white 20%, white 40%, blue 20%);
```

### Repeating gradients

The `repeating-linear-gradient()` function.

## 11.1.2 Using radial gradients

Radial gradients start at a single point and proceed outward in all directions.

By default, the gradient is centred in the element.
