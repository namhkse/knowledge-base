# Flexbox

Flexbox is a new method for laying our element on the page.
It's more predicatable and offers new methods for laying out elements on the page.

# 5.1 Flexbox principles

Apllying `display: flex` to an element turns it into a *flex container*,
and its direct children turn into *flex items*.

By default, flex items align side by side, left to right, all in one row.
- The flex container fills the width like a block element.
- But the flex item may not fill the widht of their flex container.
- The flex items are all the same height.

> TIP: You can also use `display: inline-flex`

Inline, inline-block ... only affect the element they are applied to.
Instead, a flex container affects the layout of the elements within.

# 5.2 Flex item sizes

You could use `width` and `height` properties, but flexbox provides more options
for sizing and spacing.

`flex: 2` = `flex: 2 1 0%`

flex-grow: 2;
flex-shrink: 1;
flex-basic: 0%;

## 5.2.1 Using the flex-basis property

The flex basis defines the size of an elment - an initial main size.

The flex-basic can be set to any value that would apply to width.
If not it determines the element's size by the contents.

Width will be ingored if flex-basic has the value that is not `auto`.

Once this initial mainsize is established for each flex item, they may need to grow
or shrink in order to fit the flex container along the main axis.

## 5.2.2 Using flex-grow

Once flex-basis is computed for each flex item, they will add up to some width.

This width may not fill the width of teh flex container, **leaving a remaider**.

The remainder will be consumed by the flex items based on their `flex-grow`.

## 5.2.3 Using flex-shrink

After determining the inital main size of the flex items, they could exceed the size
avilable in the flex container.

Without flex-shrink, this would result in an overflow.

The flex-shrink value for each time indicates it should shrink to prevent overflow.

flex-shrink: 0 means it will not shrink.

A higher value will shrink more than a lower value.

## 5.2.4 Some pratical uses

`flex: one | flex: none | flex: one`

`flex: 0 0 200px | flex: 1 `: a column has a fixed width, the other grows wider.

`flex: 0 0 200px | flex: 1 | flex: 0 0 200px`: the Holy Grail layout.

`flex: 50% | flex: 25% | flex: 25%`: Items grow to percentage widths.
