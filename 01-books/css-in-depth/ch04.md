# 4.1 The purpose of floats

A float pulls an elemnt (often an image) to one side of its container, allowing the document flow to wrap around it.

A floated element is removed from the normal document flow and pulled to the edge of the container.
If you float multiple elements in the same direction, they'll stack alongside one another.

> TIP It's usually easiest to lay out the large regions of a page first, then work yoru way to the smaller elements within.

**The double container pattern.**    
You achive it by palcing your content inside two nested conaineers then set margins on the inner container to position it whithin the outer one.

```css
.container {
    max-width: 1080px;
    margin: 0 auto;
}
```

Auto left and righ margisn will grow to fill the aviable space, centering teh element within the outer container.

## 4.3.1 Establishing a block formatting context

BFC is a region of the page in which elements are laid out.
A block formating conext itself is aprt of teh surronding document flow, but it isolates its contents from the outside context.

This isolation does 3 things:
- It contains the top and bottom margins of all elements within it. They won't colapse with margins of elements outside of the BFC.
- It contains all floated elements within it
- It doesn't overlap with floated elements outside the BFC 

A BFC creates an independent layout environment for its contents.

You can establish a new BFC in serveral ways
- float: left / right
- BEST overflow: hidden / auto / scroll
- GOOD (width will grow to 100%) display: inline-block / table-cell, flex / inline flex / grid ... block containers
- position: absolute / fixed
