# Transitions

Elements can fade out, menus can slide in, coloers can shift from one 
value to another, and the easist way to do any these is with transitions.

## 14.1 From here to there

The `transition-*` family of properties.

If these are applied to an element while one of its property values changes,
then that property will transition instead of changing immediately to the
new value.

The `transition-property` property specifies which properties to transition.
The special keyword `all` means to transition any properites that change.

The `transition-duration` property indicates hwo long the transition will take before reaching the final value.
