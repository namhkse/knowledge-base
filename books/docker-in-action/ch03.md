# Software installation simplified

## 3.1 Identifying software

You want to install a program called TotallyAwesomeBlog 2.0

### 3.1.1 What is a repository

A repository is a named bucket of images.

`<registry host>/<username>/<shortname>`

A repository can hold serveral images. Each of the images in a repository is identified uniquely with tags. 

### 3.1.2 Using tags

Identify an images and create useful aliases.

A image can have several tags. 
For example, the java repository on Docker has tags: 7, 7-jdk, 7u71, openjdk-7

## 3.2 Finding and installing software

Docker Hub is default.

### 3.2.1 Docker Hub from the command line

`docker login` command to log in to Docker Hub.

`docker logout` command to log out.

Find software to install:
- Go to website Docker Hub
- Use `docker search <software-name>` command

### 3.2.4 Images as files

Docker provides a command to load images into Docker form a file.

The `docker load` command, you need a image file

The `docker save` command is used to export a image to a file.

### 3.2.5 Installign from a Docker file

`docker build -t ...`

A Dockerfile is a script that describes steps for Docer to take to build a new image.

Distributing a Dockerfile is similar to distributing image files.
