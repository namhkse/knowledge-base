# What is a bounded context?

The solution in DDD is trivial: divide the ubiquitous language into multiple smaller languages,
then assign each one to th eexplicit context in which it can be applied: its bounded context.

For example, the Marketing context has term lead, the Sales context has term lead.

## Model Boundaries

A model is not a copy of the real world but a construct that helps us make sence of a complex system.

A model cannot exist without a boundary, it will expand to become a copy of the real world.

The example of maps as models.
Each map has its specific context - aerial, nautical, terrain, subway.
A map is useful and consistent only within the scope of its specific purpose.

Bounded contexts allow defining distinct models according to different problem domains.

> Bounded contexts are the consistency boundaries of ubiquitous languages.

## Unbiquitous Language Refined

A ubiquitous language is ubiquitous only in the boundaries of its bounded context.

## Scope of a Bounded Context

The ubiquitous language only helps to identify the widest boundary of that language.
