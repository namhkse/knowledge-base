# Fundamental Patterns

## Big Ball of Mud

Architectures refer to the absence of any discernible architecture structure as Big Ball of Mud.

A big ball of mud describe a simple scripting application with event handlers wired directly to database calls,
no internal structure.

## Unitary Architecture

When software originated, there was only the computer.

## Client/Server

Two-tier or client/server architecture.

Many different flavors of this architecture exist:
- Desktop + database server
- Browser + web server

## Monolithic vs Distributed Architectures

- monolithic
  Single deployment unit of all code

- distributed
  multiple deployment units, connect through remote access protocols

Monolithic
- Layered architecture
- Pipeline architecture
- Microkernel architecture

Distributed
- Service-based architecture
- Event-driven architecture
- Space-based architecture
- Microservices architecture

Distributed architecture styles have more powerfull in term performance, scalability, availability but have significant trade-offs.
