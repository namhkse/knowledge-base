# Topology

The microkernel architecture stlye is a simple monolithic architecture consisting of 2 components:
- a core system
- plug-in components

## Core System

Defines as the minimal functionality required to run the system.

For example: the IDE is text editor.

Don't put plug-in component logics into the core system.
