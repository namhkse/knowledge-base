### Breadth-first search

Breadth-first search is a different kind of search algorithm. It can help anwser two types of questions.

Question 1: Is there a path from node A to node B

Question 2: What is the shortest path from node A to node B.

## Finding the shortest path

These are two questions that breadth-first search can anwer for you.
1. Is there a path from node A to node B ?
2. What is the closest path from node A to node B ?

You saw how to answer question 1.
Now, let's try to anwer question 2.

Can you find the closest mango seller ?
For example, your friends are first-degree connections, and their friends are second-degree connections.

You'll prefer a first-degree connection to a second-degree connection.
So you shouldn't search any 2nd-degree connections before you make sure you don't a 1st-degree connection who
is a mango seller.

The way BFS works, the search radiates out from the starting point.
Who will be checked first, Claire or Anuj ?
Claire is a first-degree connection, Anuj is a 2nd-degree connection. So Claire will be checked before Anuj.
