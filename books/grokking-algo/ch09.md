# The knapsack problem

The simple solution: you try possible set of goods and find the set that gives you the most value

no item 0
guitar 1500
stereo 3000
laptop 2000
guitar + stereo doesn't fit
guitar + laptop 3500 (Max value)
stereo + laptop doesn't fit
guitar + stereo + laptop doesn't fit

This works, for 3 item you have to calculate 8 sets.

0 item 1 possible
2 items 6
3 items 1
Total 8

4 items
0 item 1
1 item 4
2 items 4 * 3 = 12
3 items 4 * 3 * 2 = 24
4 items 1

Dynamic programming starts by solving subproblems and builds up to solving the big problem.
